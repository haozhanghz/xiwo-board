# 0.1.1 质量检查与优化

检查日期：2026-10-22。基线：远端 `main` 的 `e385410`（0.1.1）。本轮修改尚未发布新版。

这次通过源码检查、已有界面截图审阅和核心算法回归，确认并修复了以下问题。当前环境是 Linux，未将静态检查或兼容测试视为 macOS 界面验收。

## 已修复的问题

| 优先级 | 触发方式与原有问题 | 修改 |
| --- | --- | --- |
| P1 | 笔迹被简化为两个远端点后，橡皮擦在线段中间经过却擦不中 | 按圆与线段的交点切分笔迹，插值保留压力；旋转笔迹切分后保持位置、透明度和其他属性 |
| P1 | 文本仍在画布内输入时直接保存、切页或开始授课，最新输入可能尚未进入课件 | 保存、导航、撤销、内容修改和授课前统一提交输入；名称也支持未按回车就保存；属性编辑保留已提交的正文 |
| P1 | 损坏 ZIP 的文件名长度超出实际数据时，`subdata` 越界会终止应用；内容损坏可能被静默读取 | 检查目录及文件边界、CRC 和解压长度，拒绝不支持的加密/跨盘/ZIP64 条目，防止解压结果超过声明大小 |
| P1 | `.xwb` 无页面、尺寸无效、表格数组不匹配时，编辑器或渲染器可能崩溃；未来格式和缺失资源未明确报错 | 在进入编辑器前验证结构和格式版本，缺失资源给出错误；位图入口拒绝无效尺寸 |
| P1 | 准备或保存录屏期间结束授课、退出应用，可能过早关闭窗口或退出；录制错误后界面状态可能滞留 | 等待开始/停止任务收尾；只处理当前输出的回调，记住早到的完成回调；失败或超时给出错误，不当作成功保存 |
| P2 | 只限制录制宽度时，竖屏输出仍可能超过编码尺寸；屏幕像素尺寸换算不一致 | 根据捕获区域的点尺寸与像素比例换算，两边均限制在 3840×2160 范围内，保持比例与偶数尺寸 |
| P2 | 循环播放的通知监听保留播放器；快速切页后旧页延迟自动播放；反复授课可能保留整份课件快照 | 停播时移除监听，导航/画布拆除时停播，取消旧页自动播放；关闭授课时清理面板、监听与托管视图的引用 |
| P2 | 点击空白处的橡皮也产生撤销点、修改标记及整页重绘 | 仅在实际擦除时记录撤销和内容变化，保留锁定笔迹；仅揭开蒙层不修改课件 |
| P2 | 长笔迹在每次拖动时因枚举中的数组复制而反复分配；页面缩略图随其他 UI 状态反复渲染；图片缓存持续增长 | 使用独立的连续笔迹缓冲区，启用缩略图行相等比较和内容缓存；缩略图缓存预算 32 MiB、解码图片缓存预算 128 MiB，并设置数量限制 |
| P2 | 更新包在主线程整包读取并计算哈希，可能阻塞操作；重复点击可重复下载，失败后留下临时文件，重新检查可覆盖待安装状态 | 在后台按 1 MiB 分块校验，限制重复操作，清理暂存目录并保留待安装状态；缺少校验文件时不进入安装 |
| P2 | 关闭主窗口后才询问保存，取消时窗口可能已消失；多个主窗口共享单份编辑状态 | 主窗口关闭统一经过退出检查；使用与单课件模型一致的单主窗口 |
| P2 | 备注输入没有自己的撤销起点，撤销后文本框可能显示旧内容 | 为连续备注输入记录撤销起点，随模型更新同步文本框 |

## 界面与易用性

- 授课工具栏根据可用屏幕宽度依次收紧、隐藏文字，必要时允许横向滚动，避免两端操作超出屏幕。新增 1000 点宽度的截图检查入口。
- 图标工具、形状、笔宽、颜色和排列操作提供可访问名称及选中状态；紧凑工具按钮扩大到至少 36 点宽的点击区域，颜色按钮扩大到 26×26 点并可换行。
- 首尾页面的上一页/下一页按钮禁用；结束授课期间禁用工具栏，防止重复收尾。
- 数值输入拒绝 NaN/无穷值，无法解析时恢复显示当前值，避免非法数值污染几何数据。
- 授课期间禁用新建、打开和关闭课件，避免编辑器切换文档而授课窗口仍引用旧文档。

上述调整改善点击目标、状态反馈和窗口适配。触控板、数位板、VoiceOver、键盘焦点顺序和真实屏幕上的遮挡情况，仍需以下 Mac 验收。

## 已执行的验证与边界

- Swift 6.0.3：全部 Swift 源码、测试和 `Package.swift` 通过语法解析；`git diff --check` 通过。
- 新增 16 个回归用例，覆盖笔迹、损坏压缩包、文档结构、录制尺寸、无效渲染尺寸，以及输入提交后的保存/切页/撤销。
- 其中 12 个核心用例在 Linux 下执行通过。临时适配层使用 Foundation 几何、zlib 和 OpenSSL 代替 Apple 的几何/压缩/哈希接口；适配层仅位于 `/tmp`，不进入产品。这验证了相关算法与边界处理，未验证 Apple 框架实现、原生渲染或界面。
- 已尝试完整 `swift test`，因 Linux 缺少 `CoreGraphics` 无法构建。原生测试、应用构建、真实录屏与界面交互尚未通过 Mac 实测，不能据此声称全部检查通过。
- 未采集 Mac 上的帧率、CPU、内存峰值或输入延迟；缓存预算也不是整个应用的内存上限。尚未量化性能提升。

## Mac 验收步骤

先在 Apple 芯片、macOS 15+、Xcode 16+ 环境运行：

```bash
swift test
./scripts/build-app.sh
build/XiwoBoard.app/Contents/MacOS/XiwoBoard --snapshot /tmp/xiwo-qa
open build/XiwoBoard.app
```

1. **保存与关闭**：编辑已有文本，未退出文字编辑就按 ⌘S，重新打开检查正文；名称输入中文及中间空格，不按回车直接保存。分别在切页、导出、进入授课时检查正文。点击红色关闭按钮后选择取消，窗口和内容应保留。
2. **笔迹与撤销**：画一条长直线，在中间点擦；旋转后重复，检查缺口位置及颜色/透明度。擦空白处应不产生修改标记或新撤销点，锁定笔迹应保留。连续书写 30 秒，检查输入是否跟手；备注输入后撤销/恢复，检查正文与备注框同步。
3. **窄屏和键盘**：检查 1000×640 编辑窗口及 1024 点宽授课屏幕，确认结束授课、录制、翻页均可到达。检查导出的 `editor-1000.png`、`toolbar-820.png`、`present-toolbar-1000.png`。用 VoiceOver 检查图标名称和选中状态，并用 Tab 完成主要工具操作。
4. **媒体与释放**：循环播放音视频后关闭或切页，确认声音停止；连续快速翻页，旧页媒体不得延迟启动。重复进入/退出授课、打开/关闭设置面板各 30 次，用 Instruments 检查播放器、托管视图及课件快照是否释放。
5. **录屏收尾**：分别在准备中、录制中、保存中结束授课或退出；测试麦克风拒绝、磁盘写入失败、横屏 6K 与竖屏。成功保存的 MP4 应能在 QuickTime 完整播放；失败必须有反馈，不能一直停在录制状态。
6. **更新**：使用测试发布包验证正确校验、错误校验、缺少校验文件、下载失败重试和待安装时再次检查。下载与校验时继续编辑，确认界面响应，并确认临时目录清理。
7. **性能测量**：用同一份 100 页含图片课件对比修改前后，记录打开/翻页耗时、长笔迹输入延迟、内存峰值和录屏期间 CPU；截图或代码检查无法代替这项测量。
