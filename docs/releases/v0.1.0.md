适用于 Apple 芯片 Mac 的原生课堂白板，第一个公开版本。备课时编辑课件，上课时全屏授课、板书、录屏讲课。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.0-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹。
2. 这个应用没有经过 Apple 公证（只有 ad-hoc 签名），第一次打开时系统会提示「无法验证」并拦下。任选一种方法放行：
   - **系统设置**：先双击打开一次，看到提示后点「完成」；然后打开「系统设置 › 隐私与安全性」，滚到页面底部，在 XiwoBoard 那一行点「仍要打开」，输入密码确认。
   - **终端**：运行 `xattr -cr /Applications/XiwoBoard.app`，之后就可以正常双击打开。

   macOS 15 起，右键 › 打开已经不能绕过这个提示，请用上面两种方法之一。
3. 第一次录屏讲课时，系统会请求「录屏与系统录音」和「麦克风」权限。授权后需要退出并重新打开应用。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。不支持 Intel Mac。

## 这个版本包含

- **编辑**：页面缩略图栏、硬笔/毛笔/荧光笔、点擦/笔画擦、39 种形状、文本、表格、图片、音视频、组合与对齐、蒙层、授课克隆、超链接、书写格背景、撤销恢复。
- **授课**：全屏授课，底部工具栏可切换普通或简单样式，另有翻页动画、激光笔、聚光灯、放大镜、计时器、板中板和页面列表。
- **录屏讲课**：录制屏幕和麦克风，电脑声音可选，输出 MP4 到「影片 › XiwoBoard 录课」。「隐藏工具」一键收起全部面板，只露出课件；开启「只录课件」后，工具栏、计时器等面板不会出现在视频里，老师自己仍然看得到。
- **文件**：原生 `.xwb` 格式；可以打开和导出 `.enbx` 课件（常见元素）；可以导出 PDF 和每页图片。

## 已知限制

- `.enbx` 只支持形状、文本、图片、音视频、组合、背景和备注；学科元素和课堂活动会跳过并提示。目前只用本应用自己导出的文件测试过。
- 大部分学科工具、课堂活动、元素动画，以及截图、桌面批注、投屏、副屏还没有做，进度见 [功能清单](https://github.com/haozhanghz/xiwo-board/blob/main/docs/FEATURES.md)。
- 没有云课件和账号功能。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
