这一版修好了上次测试发现的问题：改字号后文字出框、取消组合后变样、音频不好操作、橡皮擦漏擦，以及导出 `.enbx` 丢样式。

## 修复

- **文字不再跑出框**：改了字号、字体或文字以后，文字框会自动长高，装下全部文字，最后一行也能点中。手动拉高过的文字框保持原来的高度，放不下时才长高。
- **取消组合不再变样**：旋转过、调过透明度的组合，取消组合后每个对象都保持原来的位置、角度和透明度，锁定、蒙层和超链接也一起保留。调过透明度的组合，组里的对象现在也会按组合的透明度显示。
- **音频播放条**：播放音频时，音频对象上面会出现一条播放条，有播放/暂停、进度、时间和关闭按钮。音频对象再小，这些按钮也都在。
- **橡皮擦快速划过不漏**：橡皮擦现在按划过的整片区域擦除，划得再快，中间的笔迹也会被擦断。按下到抬起算一次擦除，撤销一次就能整个恢复。
- **导出 `.enbx` 保留更多内容**：下划线、文字背景色、透明度、文字前后的空格、页面切换动画、页面名称都会保留；田字格等书写格背景用 XiwoBoard 再打开时原样恢复，在其他软件里显示成一张背景图片；坐标轴这类从下往上画的箭头不会再反过来。
- **导出 `.enbx` 前先提醒**：课件里有 `.enbx` 存不下的内容时（比如笔迹会变成形状、表格会变成文字），导出前会列出来，可以继续导出或者取消。完整的课件请保存为 `.xwb`。
- **暂停过的录像在其他软件里也正常**：暂停前后录下的几段现在接成一条连续的时间线，用 FFmpeg 或剪辑软件打开也不会出现时间倒退。
- **录制时工具栏不再跳动**：计时的数字宽度固定，工具栏不会随着时间变宽变窄，「停止」按钮的位置不变。
- **不保留授课修改时不再显示「未保存」**：从保存过的课件开始授课，结束时选择不保留，课件回到原样，也不会再提示保存。
- **读屏更好用**：插入表格的网格每一格都是按钮（读作「插入 3 行 3 列的表格」这样），背景模板按钮有了名称，录制按钮会读出已录的时间。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.11-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「XiwoBoard › 检查更新…」里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 从 0.1.9 或 0.1.10 更新上来的，录屏和麦克风权限会保留。还在用 0.1.8 或更早版本的，更新后要按 [0.1.9 的说明](https://github.com/haozhanghz/xiwo-board/releases/tag/v0.1.9)重新授权一次。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
