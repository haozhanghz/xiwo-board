更新以后不用再重新给录屏、麦克风权限。

## 改进

- **更新不丢权限**：以前每个版本的签名都不一样，系统会把更新后的 XiwoBoard 当成新应用，设置里明明开着，录制时还是要权限。从这个版本起，安装包用项目固定的证书签名，以后再更新，权限会一直保留。
- **从旧版本升级时还要最后授权一次**：装上 0.1.9 后，如果开始录制时又提示要权限，打开「系统设置 › 隐私与安全性 › 录屏与系统录音」，选中 XiwoBoard 点「−」删掉，然后退出并重新打开 XiwoBoard，开始录制时允许，再按提示重新打开一次。也可以先退出 XiwoBoard，在「终端」里运行 `tccutil reset ScreenCapture io.github.haozhanghz.xiwoboard`（麦克风是 `tccutil reset Microphone io.github.haozhanghz.xiwoboard`）。
- 录屏权限的提示里也写上了这种情况的处理办法。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.9-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「XiwoBoard › 检查更新…」里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 安装包用项目自己的证书签名，不是 Apple 开发者证书，所以第一次打开时仍会被拦下，按上一步放行即可。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
