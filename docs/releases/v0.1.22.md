这一版让插入的文本框和形状更好调整：文本框写完字就能拖动、缩放，选中形状或文字时旁边会出现格式条，点一下就能换颜色。

## 文本框可以拖动、缩放

- 用「文本」点一下、写完字后，工具会自动回到「选择」，和画完形状一样。按 Esc 结束输入时，文本框保持选中，可以直接拖动。
- 之后点一下文本框就能选中它：拖动可以移动，拖四周的圆点可以改大小，双击或按回车继续改字。

## 格式条：一键换颜色

- 选中形状、文本框或笔迹时，下方会出现一条格式条，点色块就能换颜色。
- 形状还可以选无填充、浅色填充或实心填充；文本框可以用「−」「+」或点中间的数字改字号。
- 新画的形状和新插入的文本，会沿用你最近在格式条里选的颜色、填充和字号。
- 格式条最右边的按钮打开属性面板，线宽、虚线、字体等更多设置在那里。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.22-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「录课 › 检查更新…」（0.1.17 及更早是「讲课板 › 检查更新…」）里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 从 0.1.9 到 0.1.21 更新上来的，录屏和麦克风权限会保留。还在用 0.1.8 或更早版本的，更新后要按 [0.1.9 的说明](https://github.com/haozhanghz/xiwo-board/releases/tag/v0.1.9)重新授权一次。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
