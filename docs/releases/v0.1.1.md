修复授课时无法开始录制、窄窗口里工具栏显示不全的问题，并加入应用内更新。

## 修复

- **录屏讲课点「开始录制」没反应**：授课工具栏里的设置弹窗在点击时会直接关闭，按钮动作没有执行。现在笔、橡皮、形状和录制的设置改用独立的浮动面板，点击外面或按 Esc 关闭。
- 录制前会先检查「录屏与系统录音」和麦克风权限，缺权限时说明去哪里打开；麦克风被关掉时可以选择不录声音继续。
- 录制按钮会显示「准备中」「保存中」，录制中再点一次直接停止；停止时先把视频文件写完整再结束。
- 很大的显示器按 4K 录制，避免超出 H.264 的尺寸上限。
- **编辑工具栏在窄窗口里显示不全**：窗口变窄时按钮先收紧，再只显示图标（鼠标悬停可看名称），右上角的「授课」按钮始终可见。

## 新功能

- **应用内更新**：菜单「XiwoBoard › 检查更新…」或首页左下角的「检查更新」。发现新版本后可以直接下载、校验并替换，然后自动重新打开。默认每天启动时检查一次，可以关闭。
  - 应用只有 ad-hoc 签名，每次更新后系统可能会再次请求录屏和麦克风权限。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.1-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 第一次录屏时，按提示在「系统设置 › 隐私与安全性 › 录屏与系统录音」里打开 XiwoBoard，然后重新打开应用。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
