## 新功能

- **暂停录制**：录制时，授课工具栏的「录制」按钮旁边多了「暂停」。点「暂停」先停下来，准备好了点「继续」接着录。暂停的这段时间不会录进视频，计时也会停住。
- 停止录制后，暂停前后录下的几段会自动接成一个视频，保存在「影片 › XiwoBoard 录课」里，声音和画面对得上。
- 暂停时不录屏幕，也不录麦克风。
- 工具都隐藏起来的时候，右下角的小按钮上也能暂停和继续；暂停时那里的小圆点是橙色的。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.10-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「XiwoBoard › 检查更新…」里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 从 0.1.9 更新上来的，录屏和麦克风权限会保留。还在用 0.1.8 或更早版本的，更新后要按 [0.1.9 的说明](https://github.com/haozhanghz/xiwo-board/releases/tag/v0.1.9)重新授权一次。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
