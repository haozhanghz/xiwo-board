选笔的粗细更好点中，还多了一档更细的笔。

## 改进

- **细笔好点中**：选粗细时，点圆点所在的那一格任意位置都能选中，不用再对准很小的圆点。授课工具栏和编辑界面的画笔设置都一样。
- **更细的笔**：粗细从五档变成六档，新加的一档只有原来最细一档的一半粗，适合写小字、画细线。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.8-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「XiwoBoard › 检查更新…」里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 应用只有 ad-hoc 签名，更新后系统可能会再次请求录屏和麦克风权限。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
