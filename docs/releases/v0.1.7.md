录屏讲课默认不再录进鼠标指针。

## 改进

- **视频里不出现鼠标**：录屏时默认不录鼠标指针，视频里只有课件和板书，不会有一个箭头在画面上晃来晃去。需要在视频里指示时，可以用激光笔：激光笔是画在课件上的，会录进去。
- 想录鼠标的，点授课工具栏上的「录制」，在弹出的选项里打开「录制鼠标指针」，再开始录制。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.7-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「XiwoBoard › 检查更新…」里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 应用只有 ad-hoc 签名，更新后系统可能会再次请求录屏和麦克风权限。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
