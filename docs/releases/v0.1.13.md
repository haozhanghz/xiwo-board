硬笔有了笔锋：写快变细、写慢变粗，带着速度提笔时收出笔尖，写出来的字更像钢笔字。

## 改进

- **笔锋**：硬笔默认带笔锋。笔走得快，线条变细；写得慢，或者用数位板时按得重，线条变粗，粗细在几个笔点之间平滑过渡。撇、钩、提这类带着速度提笔的笔画，末端收成笔尖；停住了再抬笔，末端还是圆头。笔速按屏幕上的距离算，放大缩小画布写出来一样。
- **写字时和抬笔后一个样**：写字时 GPU 画的线条和抬笔后留在页面上的笔迹粗细变化相同，抬笔时只有出锋那一小段收细，线条不跳。在一台 M3 的 Mac 上模拟 240 Hz 数位板写字，开着笔锋书写延迟和以前一样（平均约 19 毫秒）。
- 不想要笔锋，在笔的设置里取消「笔锋」，就回到粗细一致的硬笔，设置会记住。毛笔和荧光笔不受影响，以前写的笔迹也不变。
- 带笔锋的笔迹用 0.1.12 及更早的版本打开，会画成粗细一致的线；导出 `.enbx` 时笔锋不保留，导出前会提示。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.13-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「XiwoBoard › 检查更新…」里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 从 0.1.9 到 0.1.12 更新上来的，录屏和麦克风权限会保留。还在用 0.1.8 或更早版本的，更新后要按 [0.1.9 的说明](https://github.com/haozhanghz/xiwo-board/releases/tag/v0.1.9)重新授权一次。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
