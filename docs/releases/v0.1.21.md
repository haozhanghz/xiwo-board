这一版修了两个问题：展开「插入」会把工具栏挤坏，打开课件后名字变成「未命名课件」。动效也加快了。

## 插入工具单独一行

- 点「插入」后，文本、形状、图片、音视频、表格、学科工具、蒙层在工具栏下面单独展开一行，上面的工具栏宽度不变。窗口再窄，后面的按钮和「收起」也不会被挤出去或挡住。
- 再点「收起」，这一行就收回去。

## 课件名称和文件名一致

- 首页「最近打开」里显示什么名字，打开后编辑页里就是什么名字，不再显示「未命名课件」。
- 保存新课件时，在保存窗口里填的名字就是课件名称。
- 在编辑页改课件名称，文件会跟着改名，和在访达里改名一样。同一个文件夹里已经有同名课件时，会提示并保留原来的名字。

## 动效更跟手

- 悬停高亮、选中块滑动、开关，以及按钮按下后的回弹，都加快了大约三分之一。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.21-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「录课 › 检查更新…」（0.1.17 及更早是「讲课板 › 检查更新…」）里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 从 0.1.9 到 0.1.20 更新上来的，录屏和麦克风权限会保留。还在用 0.1.8 或更早版本的，更新后要按 [0.1.9 的说明](https://github.com/haozhanghz/xiwo-board/releases/tag/v0.1.9)重新授权一次。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
