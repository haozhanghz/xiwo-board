首页左上角换成新的讲课板图标，和程序坞里的一致。

## 修复

- **首页图标**：首页左上角原来是一个绿蓝渐变的画笔图形，没跟着 0.1.14 换成新图标。现在直接显示应用图标，以后换图标也会自动跟上。
- **更新后图标和名字立即刷新**：在应用里更新后，会先让系统重新登记一次应用，访达和程序坞不再继续显示缓存里的旧图标、旧名字。
- 已经装了 0.1.14、访达或程序坞里仍是旧图标的，更新到这一版后就会刷新。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.15-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「讲课板 › 检查更新…」（0.1.13 及更早是「XiwoBoard › 检查更新…」）里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 从 0.1.9 到 0.1.14 更新上来的，录屏和麦克风权限会保留。还在用 0.1.8 或更早版本的，更新后要按 [0.1.9 的说明](https://github.com/haozhanghz/xiwo-board/releases/tag/v0.1.9)重新授权一次。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
