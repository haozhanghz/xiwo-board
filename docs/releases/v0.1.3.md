更好地支持 XPPen 等数位板：毛笔收笔不再拖出细尖，用笔尾或笔侧键就能擦除。

## 改进

- **收笔不再变细**：数位板在笔离开板面前的最后一两个采样，压感接近 0，毛笔会在末尾拉出一个细尖；偶尔掉一个点，线条也会突然变细。现在这些读数沿用前一个压感，其余采样做轻度平滑，毛笔边缘更顺。
- **笔尾橡皮**：选着画笔时，把笔翻过来用笔尾就能擦除，工具栏不用切换。只有数位板报告的橡皮才会擦，鼠标不会误擦。需要笔本身带橡皮笔尾。
- **笔侧键擦除**：XPPen 默认有一个笔键是「右键单击」。选着画笔时按住这个键划过就是擦除，松开继续写，一次按住算一步撤销。鼠标右键还和以前一样。
- 新增 [数位板适配说明](https://github.com/haozhanghz/xiwo-board/blob/main/docs/TABLET.md)：XPPen 驱动怎样把笔的数据交给应用，以及推荐的 XPPen 设置。

## 推荐的 XPPen 设置

- 压感曲线保持默认（线性），平滑交给 XiwoBoard。
- 想用侧键擦除，就保留其中一个笔键为「右键单击」。
- 上课时把屏幕映射设成投影或一体机所在的显示器。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.3-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了 0.1.1 或 0.1.2 的，也可以在「XiwoBoard › 检查更新…」里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 应用只有 ad-hoc 签名，更新后系统可能会再次请求录屏和麦克风权限。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
