录课时人声更清楚：保存视频时自动把麦克风声音调到正常音量。

## 修复

- **录课声音太小**：人离麦克风稍远，录出来的讲解声音就偏小。现在保存录课时，会测一下人声的响度，把它调到和一般讲解视频差不多的音量（约 -16 dBFS）。停顿和安静的地方不参与计算，最多放大 20 dB，避免把底噪也放得太大；最响的地方会圆滑地压一下，不会破音。
- 本来就够响的录音和静音不会被改动。暂停过的录课在合并几段时一起调；没暂停过的，只重写声音、画面原样保留，调音失败就保留原录音。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.16-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「讲课板 › 检查更新…」（0.1.13 及更早是「XiwoBoard › 检查更新…」）里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 从 0.1.9 到 0.1.15 更新上来的，录屏和麦克风权限会保留。还在用 0.1.8 或更早版本的，更新后要按 [0.1.9 的说明](https://github.com/haozhanghz/xiwo-board/releases/tag/v0.1.9)重新授权一次。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
