调整授课时的快捷键，方便用数位板上的按键操作：E 可以在橡皮和笔之间来回切换，新增 C 清除本页笔迹。

## 改进

- **E 键来回切换**：以前按 E 切到橡皮后，只能用鼠标点工具栏切回笔。现在再按一次 E 就回到笔。
- **C 键清除本页笔迹**：授课时按 C，清除当前页的全部笔迹，和橡皮面板里的「清除本页笔迹」一样。误按了可以用 ⌘Z 恢复。
- 带 ⌘、⌃、⌥ 的组合键不再触发这些单键功能，比如 ⌘C 不会清除笔迹、⌘E 不会切换工具。

## XPPen 数位板怎么设置

在 XPPen 驱动的快捷键设置里：

1. 第一个键保持「笔/橡皮擦」：选着笔时按一下，笔尖变成橡皮，再按一下变回笔。
2. 第二个键从「E」改成「C」：按一下清除本页笔迹。
3. 「Command+Z」那个键用来撤销，误清除时按它恢复。

完整的按键表见 [数位板适配说明](https://github.com/haozhanghz/xiwo-board/blob/main/docs/TABLET.md)。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.5-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经放在「应用程序」里的旧版本，也可以在「XiwoBoard › 检查更新…」里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 应用只有 ad-hoc 签名，更新后系统可能会再次请求录屏和麦克风权限。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
