一轮稳定性修复：橡皮、文字保存、课件文件、录屏收尾和授课工具栏。

## 修复

- **直线笔迹从中间也能擦掉**：抬笔后笔迹会精简成少数几个点，点擦以前只看这些点，从两点之间擦过去擦不掉。现在按线段切开，旋转过的笔迹擦断后位置、颜色、透明度都不变。在空白处擦不再产生撤销步骤，锁定的笔迹不会被擦。
- **最后输入的文字不再丢**：文字还在输入时直接保存、切页、导出或开始授课，最后输入的内容也会存进去。课件名称不按回车也会保存，备注可以撤销。
- **损坏的课件不再让应用崩溃**：打开时检查压缩包和课件结构，有问题会提示。课件里缺少图片等资源时照常打开，并列出缺了哪些。
- **录屏收尾更稳**：录屏准备或保存的过程中结束授课、退出应用，会等录制完成再关；录制失败会提示，不会一直停在录制状态。竖屏和超宽屏录出来的尺寸也对了。
- **关闭主窗口时先问是否保存**，点取消窗口就留着。
- 切页后旧页面的音视频不会再延迟自动播放，循环播放的声音在关闭后会停。

## 改进

- 窄屏上授课工具栏会依次收紧、隐藏文字，再不够就可以横向滚动；首页和末页的翻页按钮会变灰。授课时不能新建、打开或关闭课件。
- 页面缩略图有缓存，图片缓存有上限，长时间上课占用的内存更少。
- 应用内更新在后台校验安装包，重复点击不会重复下载，失败后会清理临时文件。
- 图标按钮、颜色和笔宽有了 VoiceOver 能读出的名称。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.5-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「XiwoBoard › 检查更新…」里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 应用只有 ad-hoc 签名，更新后系统可能会再次请求录屏和麦克风权限。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
