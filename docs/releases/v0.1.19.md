这一版把手写和录课放到最前面：编辑页多了「录课」按钮和快捷键，不常用的插入工具收了起来，图标也重画了。

## 录课更顺手

- 编辑页右上角「授课」旁边多了「录课」按钮，点一下直接进入授课并开始录制。
- 录课快捷键：⌥⌘R 开始，⌥⌘P 暂停 / 继续，⌥⌘S 结束。授课时切到别的应用也能用，授课结束后就把这几个键还给其他应用。

## 工具栏更清爽

- 文本、形状、图片、音视频、表格、学科工具、蒙层收进「插入」按钮，默认折叠，点开后再点「收起」即可。撤销、选择、画笔、橡皮这些写字用的工具照常在外面。
- 窗口左上角的红绿灯按钮和工具栏放在同一行，工具栏上方不再空出一条，房子按钮前面也不再空出一大块。全屏时工具栏贴着左边。

## 首页

- 「打开其他课件…」「打开录课文件夹」前面加了文件夹图标，鼠标移上去会变深并出现底色。
- 最近打开的课件统一用一个图标，不再按 .enbx 和自己的格式区分。
- 去掉了侧栏里的「示例课件」。

## 新图标

- 陶土色底，左上一个手写的 x²，中间一支笔，右下角一个红色录制圆点。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.19-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「录课 › 检查更新…」（0.1.17 及更早是「讲课板 › 检查更新…」）里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 从 0.1.9 到 0.1.18 更新上来的，录屏和麦克风权限会保留。还在用 0.1.8 或更早版本的，更新后要按 [0.1.9 的说明](https://github.com/haozhanghz/xiwo-board/releases/tag/v0.1.9)重新授权一次。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
