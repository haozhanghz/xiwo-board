这一版参考 [Fluid Functionalism](https://www.fluidfunctionalism.com/) 重做了按钮、工具栏和首页的手感：高亮跟着鼠标走，选中的东西滑到新位置，按钮按下去会收一点再弹回来。功能和布局没有变。

## 工具栏

- 鼠标在工具栏上移动时，一块浅灰色高亮会滑到离鼠标最近的按钮上。按钮之间的空隙也能点，点中的就是亮着的那个。
- 选中的工具（选择、画笔、橡皮等）下面那块浅陶土色底，换工具时会滑到新工具上。鼠标移到别的按钮时，这块底会稍微变淡。
- 授课时的工具条也一样：选择、激光笔、聚光灯、放大镜之间切换时，选中的底跟着滑过去。
- 鼠标移到的按钮图标会加粗，文字粗细不变，旁边的按钮不会被挤动。

## 画笔设置

- 硬笔 / 毛笔 / 荧光笔和防抖：换选项时，浮起的白块滑到新选项上。鼠标移到别的选项上，会有一块淡一些的白块从选中处滑过去提示。选中的字加粗，旁边的字不会被挤动。
- 选中的粗细和颜色外圈也会滑到新的选择上。
- 计时器的「倒计时 / 正计时」在深色面板上，选中的一格改成比底色亮，一眼能看出选的是哪个。

## 开关和按钮

- 录屏选项、画笔设置、属性面板和更新窗口里的开关换了新样式：打开时是陶土色，关着时文字变浅，按住时圆钮会拉长。
- 按钮按下去会往里收一点，松开时慢慢弹回。
- 主要按钮统一高 36 点，计时器的「重置」和「开始」一样高，也有了悬停和按下的反馈。

## 首页

- 最近打开的课件：高亮跟着鼠标在行之间滑动，亮着的行上下的分隔线会暂时隐去。
- 最近录屏的卡片：高亮跟着鼠标在卡片之间移动，鼠标所在的卡片显示播放和分享按钮。
- 「打开其他课件…」「打开录课文件夹」在鼠标移上去时图标加粗、文字变深，文字宽度不再变化。

在「系统设置 › 辅助功能 › 显示 › 减少动态效果」打开时，高亮直接跳到目标，不再滑动。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.20-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「录课 › 检查更新…」（0.1.17 及更早是「讲课板 › 检查更新…」）里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 从 0.1.9 到 0.1.19 更新上来的，录屏和麦克风权限会保留。还在用 0.1.8 或更早版本的，更新后要按 [0.1.9 的说明](https://github.com/haozhanghz/xiwo-board/releases/tag/v0.1.9)重新授权一次。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
