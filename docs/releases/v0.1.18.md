讲课板改名为「录课」，换了新图标，文字更大、更清楚，看久了眼睛更舒服。

## 改名和新图标

- 应用改名为「录课」（英文系统里显示为 Lesson Recorder），图标换成和新界面一致的陶土色：一块写了字的板子，右下角一个录制圆点。
- 应用文件仍叫 `XiwoBoard.app`，所以在应用里直接更新就行，录屏和麦克风权限会保留。
- 录课视频的文件夹从「影片 › 讲课板录课」改名为「影片 › 录课」，第一次打开新版本时会自动把原来的视频连同文件夹一起挪过去，首页的「最近录屏」照常显示。

## 更清楚的文字

- 界面文字整体大一号：正文 14、说明 13，工具栏标签也更大。
- 灰色的说明文字加深，和背景的对比度更高；最浅的提示文字也能看清。
- 属性面板、页面列表和首页侧栏稍微加宽，输入框和按钮更高，字大了也不挤。
- 工具栏按钮之间的间距加大，标签不再挤在一起。

## 页面背景更好选

- 属性面板里的页面背景不再是一排缩略图，而是「颜色」一行的色点：白板、绿板、黑板、米黄、浅蓝，最后一个彩色圆点选任意颜色。
- 换颜色时保留已经选的书写格，格线颜色自动换成在新底色上看得清的颜色；书写格在下面一行单独选。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.18-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「讲课板 › 检查更新…」（0.1.13 及更早是「XiwoBoard › 检查更新…」）里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 从 0.1.9 到 0.1.17 更新上来的，录屏和麦克风权限会保留。还在用 0.1.8 或更早版本的，更新后要按 [0.1.9 的说明](https://github.com/haozhanghz/xiwo-board/releases/tag/v0.1.9)重新授权一次。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
