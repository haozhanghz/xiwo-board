写字更工整，录课更干净，界面焕然一新：笔迹防抖、录课自动去掉写字声，整个界面换成更安静、更清楚的暖色风格。

## 新界面

- 整体换成暖色象牙底配一个陶土色强调色，深色模式同样适配。按钮、分隔线、选中状态都统一了，每个界面只有一个最主要的按钮。
- **首页**：标题「今天讲什么课？」，左侧只留新建、打开和示例课件；最近打开的课件和最近录屏排得更整齐，录屏卡片显示中文日期。
- **编辑**：工具栏更安静，「授课」按钮更醒目；文件菜单在课件名旁边的下拉箭头里。
- **属性面板**：分区更清楚，数值框、下拉、开关重新设计，透明度和线宽直接显示数值。
- **授课**：工具栏、计时器、录制选项、页面列表和录制时的小悬浮条用同一种深色；计时器的加减按钮放到时间两边。

## 录课去掉写字声

- 笔在数位板上敲击、划写的声音以前会被麦克风录进去。现在保存录课时，用 macOS 自带的「语音突显」处理麦克风声音，只留下人声，声音和画面保持同步。
- 录制选项里有「去掉写字声」开关，默认打开。只在录麦克风、不录电脑声音时起作用。处理失败会保留原录音。一小时的录课保存时大约多花一分半钟。

## 书写更工整

- **防抖**：慢慢写时手的轻微抖动、数位板采样的跳动，以前都会原样留在线上，线条发毛、一段段地歪。现在每个笔点都会放到它前后一小段笔迹拟合出的直线上，线条变得平顺；折角和钩单独处理，仍然是尖的，字形不变。墨迹还是一直到笔尖，不会拖在笔后面，抬笔时线条也不会跳。硬笔、毛笔、荧光笔都有效。
- 在笔的设置里可以选「防抖」关、轻、中、强，默认「中」。写很小的字觉得被修圆了，可以选「轻」；数位板小、屏幕大，或者手抖得厉害，可以选「强」。
- **笔锋更稳**：笔速改为看最近约 20 毫秒笔走过的距离，数位板的抖动不再被当成速度，慢慢写的线不会忽粗忽细。粗细变化收窄到慢写约 1.1 倍、快写约 0.8 倍笔宽，变化也更缓。落笔先用原本的粗细，每一笔起头不再是一团墨。带着速度提笔照样出锋。
- 在一台 M3 的 Mac 上模拟 240 Hz 数位板写字，开着防抖的书写延迟和以前一样，平均约 19 毫秒。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.17-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「讲课板 › 检查更新…」（0.1.13 及更早是「XiwoBoard › 检查更新…」）里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 从 0.1.9 到 0.1.16 更新上来的，录屏和麦克风权限会保留。还在用 0.1.8 或更早版本的，更新后要按 [0.1.9 的说明](https://github.com/haozhanghz/xiwo-board/releases/tag/v0.1.9)重新授权一次。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
