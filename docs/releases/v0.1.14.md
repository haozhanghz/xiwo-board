XiwoBoard 改名为「讲课板」（英文名 TeachBoard），换上新图标：一支笔在课件上写下 y=sin x。首页还多了「最近录屏」，编辑器也更清爽。

## 新名字和新图标

- 中文系统里，访达、程序坞、菜单栏和窗口标题都显示「讲课板」，其他语言显示 TeachBoard。
- 安装包里的文件仍叫 `XiwoBoard.app`，所以可以照常在应用里检查更新，录屏和麦克风权限也会保留。
- 录课视频改存到「影片 › 讲课板录课」。以前「影片 › XiwoBoard 录课」里的视频会在第一次打开新版本的首页或开始录制时自动挪过去。

## 改进

- **首页「最近录屏」**：列出最新的 8 个录课视频，带封面和时长。点封面播放，分享按钮调出系统分享菜单，右键可以在访达中显示、拷贝或移到废纸篓。
- **首页以最近打开为主**：去掉了新建模板，新课件从空白开始，背景在属性面板里选；还没有文件时直接给出「新建课件」和「打开课件」。
- **编辑器**：属性面板默认收起，画布更宽；需要时点「授课」旁边的「属性」（⌥⌘I）打开，会记住你的选择。左上角加了「返回首页」。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.14-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经装了旧版本的，也可以在「XiwoBoard › 检查更新…」里直接更新，更新后菜单会变成「讲课板 › 检查更新…」。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 从 0.1.9 到 0.1.13 更新上来的，录屏和麦克风权限会保留。还在用 0.1.8 或更早版本的，更新后要按 [0.1.9 的说明](https://github.com/haozhanghz/xiwo-board/releases/tag/v0.1.9)重新授权一次。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
