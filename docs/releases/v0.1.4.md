修复应用内更新：直接在「下载」里打开 XiwoBoard 时，「检查更新」下载新版本会失败，提示「……是只读宗卷」。

## 修复

- **在「下载」里打开时也能更新**：从网上下载的 App 如果没有先拖进「应用程序」就直接打开，macOS 会把它放到一个随机的只读位置运行（App Translocation），更新程序在那里写不了文件。现在遇到这种情况，新版本会直接装进「应用程序」文件夹，重新打开后就从那里运行。更新窗口里会提前说明。从只读的磁盘映像里打开时也一样。
- 如果「应用程序」文件夹也没有写入权限，会提示先把 XiwoBoard 拖进「应用程序」再更新。

## 还停在 0.1.1–0.1.3、更新时提示「只读宗卷」的

旧版本的更新程序有这个问题，没法自己更新过来，需要手动操作一次：

1. 退出 XiwoBoard。
2. 在 Finder 里把「下载」中的 `XiwoBoard` 拖进「应用程序」文件夹（要用 Finder 拖，不要用终端的 `mv`）。
3. 从「应用程序」打开 XiwoBoard，再点「XiwoBoard › 检查更新…」，就能装上这个版本。

也可以直接下载下面的安装包，按「下载安装」的步骤替换。

## 下载安装

1. 下载下面的 `XiwoBoard-0.1.4-arm64.zip`，双击解压，把 `XiwoBoard.app` 拖进「应用程序」文件夹（替换旧版本）。已经放在「应用程序」里的旧版本，也可以在「XiwoBoard › 检查更新…」里直接更新。
2. 第一次打开时如果被系统拦下：打开「系统设置 › 隐私与安全性」，在页面底部点「仍要打开」；或者在终端运行 `xattr -cr /Applications/XiwoBoard.app`。
3. 应用只有 ad-hoc 签名，更新后系统可能会再次请求录屏和麦克风权限。

**系统要求**：Apple 芯片（M1 及以后），macOS 15 及以上。

安装包由 GitHub Actions 从这个标签对应的源码编译，`.sha256` 文件可用来校验下载是否完整。
